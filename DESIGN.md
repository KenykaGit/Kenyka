# DESIGN.md — Claude × Anthropic–inspired Design System

> Версия: 1.0 · 13 ноября 2026 · Язык: русский
>
> **Статус:** независимая, практическая реконструкция визуальных принципов Claude и Anthropic для собственных продуктов. **Неофициальный** брендбук и **не** извлечённый исходный дизайн-токен файл Anthropic. Значения размеров, цветов и состояний ниже — рекомендуемые приближения, если явно не указано иное.

## 0. Назначение и правила применения

Используй этот файл как единственный источник визуальных решений при разработке сайта, SaaS, AI-чата, документации, личного кабинета или лендинга. Цель — передать **ощущение** Claude/Anthropic: тёплый минимализм, редакционная типографика, спокойная уверенность, внимание к тексту и качественная детализация. Не копируй фирменные логотипы, иллюстрации, тексты, товарные знаки или точную компоновку чужих страниц. Создай собственную узнаваемую идентичность.

**Иерархия при конфликте:** доступность → функциональность → последовательность токенов → визуальная эстетика → декоративные эффекты.

## 1. Две связанные визуальные ветки

| | Anthropic / editorial marketing | Claude / product interface |
|---|---|---|
| Настроение | Интеллектуальное, издательское, концептуальное | Уютное, сосредоточенное, полезное |
| Фон | Тёплый кремовый, большие цветовые поля | Светлый тёплый canvas, отдельные поверхности |
| Типографика | Крупные выразительные serif-заголовки + нейтральный sans | Читабельный sans в интерфейсе, serif для акцентов |
| Композиция | Крупные поля, асимметрия, журнальный ритм | Центрированный рабочий фокус, боковая панель |
| Акцент | Терракотовый / коралловый | Приглушённый терракотовый |
| Карточки | Редко, сдержанно | Только там, где есть смысловая группировка |
| Движение | Тихое, содержательное | Быстрый отклик, без отвлекающих эффектов |

**Общее правило:** не смешивай все приёмы на одном экране. Для маркетинга — больше editorial; для рабочего продукта — больше utility.

### 2.3 Правила контраста

- Основной текст: стремись к WCAG AA, минимум 4.5:1; крупный текст — минимум 3:1.
- Интерактивные границы, иконки и focus indicators: минимум 3:1 там, где применимо.
- **Не предполагай**, что вся указанная палитра автоматически проходит WCAG: проверяй реальные пары foreground/background.
- На терракотовой заливке выбирай тёмный или белый текст только после проверки контраста. Для светлой темы часто безопаснее тёмный текст на светлой акцентной подложке.

## 3. Типографика

### 3.1 Шрифтовые роли

- **Display / editorial:** выразительная современная антиква с умеренным контрастом. Возможные независимые альтернативы: `Newsreader`, `Source Serif 4`, `Georgia`. Не заявляй, что это точные фирменные шрифты Anthropic.
- **UI / body:** `Inter`, `Source Sans 3`, `Arial`, `system-ui`; для более авторского ощущения предпочтителен `Source Sans 3`.
- **Code:** `IBM Plex Mono`, `SFMono-Regular`, `ui-monospace`.
- Для кириллицы убедись, что выбранная гарнитура имеет полноценное начертание и поддержку кириллических символов. Не допускай незаметного смешивания разных шрифтов в русских заголовках.

```css
:root {
  --font-sans: "Source Sans 3", system-ui, sans-serif;
  --font-serif: "Newsreader", "Source Serif 4", Georgia, serif;
  --font-mono: "IBM Plex Mono", ui-monospace, monospace;
  --text-xs: .75rem;
  --text-sm: .875rem;
  --text-base: 1rem;
  --text-lg: 1.125rem;
  --text-xl: 1.25rem;
  --heading-sm: clamp(1.5rem, 2.5vw, 2rem);
  --heading-md: clamp(2rem, 4vw, 3.5rem);
  --heading-lg: clamp(3rem, 6.5vw, 6rem);
}
body { font-family: var(--font-sans); font-size: var(--text-base); line-height: 1.55; }
h1, h2, h3 { text-wrap: balance; }
.editorial-heading { font-family: var(--font-serif); font-weight: 400; line-height: 1.05; letter-spacing: -.035em; }
.ui-heading { font-family: var(--font-sans); font-weight: 600; line-height: 1.2; letter-spacing: -.025em; }
p { max-width: 72ch; }
```

## 4. Layout, сетка, отступы

### 4.1 Spacing scale

`4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 128 px`.

```css
:root {
  --space-1: 4px; --space-2: 8px; --space-3: 12px;
  --space-4: 16px; --space-5: 24px; --space-6: 32px;
  --space-7: 40px; --space-8: 48px; --space-9: 64px;
  --space-10: 80px; --space-11: 96px; --space-12: 128px;
  --container: 1200px; --reading-width: 720px;
  --radius-xs: 6px; --radius-sm: 10px;
  --radius-md: 14px; --radius-lg: 20px;
  --radius-xl: 28px; --radius-pill: 999px;
}
```

- Marketing container: 1120–1280 px; reading column: 640–760 px.
- Desktop page gutter: 40–64 px; tablet: 24–32 px; mobile: 16–20 px.
- Marketing section vertical padding: 96–144 px desktop, 64–88 px tablet, 48–72 px mobile.
- UI card padding: 16–24 px; major panel: 24–32 px.
- Grid: 12 columns desktop, 6 tablet, 4 mobile; gap 16–32 px.
- Избегай одинаковых карточек для каждой секции: большие свободные поля часто работают лучше.

### 4.2 Breakpoints (рекомендуемые)

`sm: 640px`, `md: 768px`, `lg: 1024px`, `xl: 1280px`, `2xl: 1536px`.

### 4.3 Радиусы и границы

- Поля и кнопки: 10–14 px; карточки: 14–20 px; диалоги: 20–24 px.
- Pill только для чипов и отдельных компактных действий.
- Border: 1 px `var(--border)`; визуальная иерархия преимущественно через фон и расстояние, а не сильные тени.
- Тени минимальные: `0 2px 12px rgb(30 25 20 / 0.05)` для плавающих поверхностей, `0 12px 40px rgb(30 25 20 / 0.12)` для диалогов.

## 5. Компоненты

### 5.1 Buttons

**Primary:** заливка `--accent` либо тёмная нейтральная (зависит от контекста), проверенный контраст текста, высота 40–44 px, горизонтальный padding 16–20 px, radius 10–12 px. **Secondary:** `--surface-muted` с основным текстом. **Tertiary / ghost:** без заливки, мягкий hover. **Destructive:** только для разрушительных действий.

Состояния: default, hover, pressed, focus-visible, loading, disabled. Disabled не должен быть единственным способом объяснить невозможность действия. Иконка обычно 16–18 px; gap 8 px. Не используй больше одного визуально главного CTA в одной локальной группе.

### 5.2 Input / textarea / select

- Высота single-line: 44–48 px; textarea auto-grow с ограничением высоты.
- Светлая нейтральная поверхность, тонкая граница или её отсутствие при очевидном контуре.
- Label над полем; placeholder не заменяет label.
- Focus: видимый 2 px outline с offset 2 px, без layout shift.
- Ошибка: текст причины под полем + `aria-describedby`, а не только красная рамка.
- Поиск и чат-композер: большие удобные поля, аккуратные встроенные иконки.

### 5.3 Cards

- Card не обязателен. Используй для самостоятельного объекта: проект, документ, тариф, интеграция.
- Фон `--surface` или `--surface-muted`, border 1 px, radius 16–20 px, padding 20–28 px.
- Заголовок, краткое описание, одно понятное действие. Не вкладывай карточки друг в друга без причины.
- Hover — лёгкое изменение поверхности, границы или подъём на 1–2 px; не тяжёлый glow.

### 5.4 Navigation

**Marketing:** спокойный header 64–80 px, логотип слева, 3–6 ссылок, CTA справа. Sticky только при реальной пользе; на мобильном — доступное меню.

**App:** боковая панель 240–280 px desktop, отдельный основной контент, верхняя зона с названием контекста и вторичными действиями. Sidebar можно свернуть; на мобильном — drawer. Активный пункт обозначай и цветом, и фоном/формой, и `aria-current`.

### 5.5 Tabs, chips, dropdowns

- Tabs: короткие названия, активное состояние через нижнюю линию или мягкую подложку; клавиатурная навигация.
- Chips: маленькие, функциональные, нейтральные; не делай все чипы терракотовыми.
- Dropdown: ширина по содержимому, max-height, keyboard navigation, Escape, focus management, elevation только при необходимости.

### 5.6 Dialog, toast, tooltip

- Dialog: max-width 480–640 px для стандартных задач; 20–24 px radius; backdrop с умеренным затемнением; корректный focus trap и возврат фокуса.
- Toast: короткое сообщение, ненавязчивое появление, `role=status` для обычных событий, `role=alert` только для важных ошибок.
- Tooltip: дополнительная информация, никогда не единственный способ объяснения критичной функции.

### 5.7 Tables, lists, empty states

- Таблицы: выравнивание чисел вправо, тихие разделители, понятные заголовки, hover/focus для интерактивных строк.
- Списки: текст важнее декоративных контейнеров.
- Empty state: один простой символ/иллюстрация, ясный заголовок, одна строка объяснения и действие; избегай клише «космонавт на луне».

## 6. Claude-like AI Chat — шаблон продукта

### 6.1 Композиция

```text
┌─────────────────────┬────────────────────────────────────────────────────┐
│ Sidebar             │ Top bar: context / model / actions                 │
│ New conversation    ├────────────────────────────────────────────────────┤
│ Search              │                                                    │
│ Projects            │          Main conversation / welcome               │
│ Recent conversations│          max-width ~760–840px                     │
│                     │                                                    │
│ Account / settings  │          Composer anchored near bottom            │
└─────────────────────┴────────────────────────────────────────────────────┘
```

- Рабочая область: `--bg`, спокойная и не перегруженная.
- Контент разговора: max-width 760–840 px, удобная длина строк, вертикальный ритм 20–32 px.
- Сообщения пользователя можно выделять мягкой подложкой; ответы ассистента лучше оставлять ближе к обычному документному тексту, без массивных пузырей.
- Composer: radius 16–22 px, padding 12–16 px, кнопки вложений/отправки, явный focus, поддержка длинного текста и клавиатуры.
- Markdown-ответы: аккуратные заголовки, списки, таблицы, цитаты; код в отдельном блоке с кнопкой копирования.
- Streaming: не прыгать по ширине, не анимировать каждое слово, сохранять скролл-контекст пользователя.
- Loading: тихий индикатор статуса; ошибка — конкретное объяснение и retry.
- Mobile: sidebar в drawer, composer не перекрывает клавиатуру, safe-area, кнопки с удобной областью нажатия.

### 6.2 Состояния

Welcome / empty conversation; composing; uploading; generating; tool-in-progress; completed; cancelled; error; offline; rate limit; long content; code block; attachments; search results; message actions; edit/retry. Для каждого состояния предусмотри дизайн до реализации.

### 6.3 Контент

- Ясные, спокойные, человеческие формулировки.
- Избегай рекламного восторга, чрезмерных эмодзи и длинных инструкций там, где интерфейс может быть самоочевидным.
- Технические детали — по запросу, а не в центре каждой страницы.

## 7. Anthropic-like marketing — шаблоны страниц

### 7.1 Homepage

1. **Header:** минимальный, без перегруза.
2. **Hero:** крупный editorial заголовок, короткий подзаголовок, 1–2 действия, много воздуха.
3. **Statement:** сильная короткая мысль на контрастном тёплом фоне.
4. **Capabilities:** 2–4 содержательных блока с переменным ритмом; не обязательно сетка из одинаковых карточек.
5. **Proof:** реальные примеры, исследования, кейсы или цитаты.
6. **Editorial section:** крупная типографика + выразительный визуальный объект.
7. **Closing CTA:** одно чёткое предложение.
8. **Footer:** структурированные ссылки, юридическая информация, контакты.

### 7.2 Product page

Hero → Product preview → Primary workflow → Benefits → Detailed features → Trust/FAQ → CTA. Показывай настоящий продукт и его ценность, а не абстрактные AI-орбы.

### 7.3 Article / research page

Крупный заголовок, дата/автор, удобная reading-column, 16–18 px основной текст, serif для цитат, аккуратные сноски, таблицы и графики. Структура важнее декоративных эффектов.

### 7.4 Visual language

- Большие однотонные цветовые поля и выразительные композиционные паузы.
- Геометрические, абстрактные или материальные изображения — только если поддерживают смысл.
- Уместны приглушённые терракотовые, песочные, графитовые, кремовые тона.
- Допустимы editorial фото и диаграммы, но не случайные стоковые картинки.
- Не используй чужой фирменный знак Claude/Anthropic как собственный логотип.

## 8. Motion & interaction

```css
:root {
  --ease-out: cubic-bezier(.22, 1, .36, 1);
  --duration-fast: 120ms;
  --duration-normal: 180ms;
  --duration-slow: 280ms;
}
.interactive {
  transition: background-color var(--duration-normal) ease,
              border-color var(--duration-normal) ease,
              transform var(--duration-normal) var(--ease-out);
}
.interactive:focus-visible {
  outline: 2px solid var(--focus);
  outline-offset: 2px;
}
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
}
```

- Hover 120–180 ms; панель/диалог 180–280 ms; переход секции не более 400 ms без содержательной причины.
- Не делай бесконечные фоновые анимации, parallax и glowing borders по умолчанию.
- Анимация должна объяснять изменение состояния, а не демонстрировать технологию.

## 9. Иконки, иллюстрации, графики

- Один набор иконок на весь продукт (например, Lucide), stroke 1.75–2, размеры 16/18/20/24 px.
- Иконка рядом с подписью там, где смысл может быть неоднозначен.
- Графики: минимум линий сетки, нейтральные подписи, один акцент для главного ряда; цвет не единственный канал передачи значения.
- Иллюстрации: простые, оригинальные, без чрезмерного 3D, не заменяют содержательные скриншоты.

## 10. Responsive & accessibility

- Mobile-first, адаптивная типографика через `clamp()`.
- Интерактивные цели по возможности 44×44 CSS px, особенно на мобильных.
- Полная клавиатурная навигация, видимый focus, правильный tab order.
- Семантические HTML-теги, корректные заголовки H1→H2→H3, `label`, `aria-*` только где необходимо.
- Никакой информации исключительно цветом; для ошибок — текст.
- Контент не должен обрезаться при 200% zoom; проверяй 320 px viewport и длинные русские слова.
- Уважай `prefers-reduced-motion`, системную тему и настройку контраста.
- Не создавай горизонтальный скролл страницы из-за длинного кода: скролл должен быть локальным в code block.

## 12. Паттерны, которых избегать

- Градиент purple→blue как универсальный «AI look».
- Холодный SaaS-дизайн с десятками ярких карточек.
- Повсюду стекло, blur, glow, тяжёлые тени.
- Одинаковые 3-column cards на каждой секции.
- Слишком маленький текст, особенно 12–13 px для основного контента.
- Случайные радиусы, несогласованные отступы и иконки.
- Массивные чат-пузыри и декоративные аватары у каждого ответа.
- Serif в таблицах, формах, меню и коде.
- Слепое копирование Claude/Anthropic branding, иллюстраций, названий, favicon.
- Недоступные hover-only взаимодействия и анимации без reduced-motion.

## 13. Правила для AI-агента / Claude Code / Cursor

> **Прочитай DESIGN.md до генерации любого UI.** Создавай оригинальный интерфейс, вдохновлённый тёплым editorial-минимализмом Anthropic и утилитарной ясностью Claude. Используй только токены из этого файла. Для лендингов отдавай приоритет выразительной serif-типографике, крупным полям и асимметричному editorial-ритму. Для приложений — sans UI, узкой читабельной колонке, нейтральным поверхностям, сдержанным кнопкам и ясной иерархии. Не используй generic AI gradients, glassmorphism, неон, перегруженные карточки и случайные компоненты. Поддерживай dark mode, responsive, keyboard navigation, reduced motion и WCAG AA. Если токен или компонент отсутствует — предложи новое правило и добавь его в DESIGN.md, а не хардкодь стили по всему проекту. Не копируй фирменные логотипы, названия и тексты Claude/Anthropic.

## 15. Применение в портфолио Kenyka

- `Dark` сохраняет существующий дизайн; `Claude Mode` использует светлые токены этого документа. По умолчанию выбран Dark, явный выбор сохраняется в браузере.
- Шрифты без сетевых загрузок: Georgia для editorial-заголовков, system-ui / Segoe UI для интерфейса.
- Размеры, сетки, отступы и масштабирование общие у двух тем. Заголовки занимают одинаковые по размеру блоки; смена гарнитуры не сдвигает соседние элементы.
- Переключатель — кнопка 44×44 px без меню и текста: текущая иконка Dark или терракотовый лучевой знак Claude Mode. Название следующего действия доступно через `aria-label` и `title`.
- `--theme-duration: 600ms` — плавная смена всей палитры через View Transitions; без поддержки API используются переходы цветов. Reduced motion отключает анимацию.
- Переход между разделами — 850 ms, раскрытие проекта — 650 ms, панели достижения — 550 ms. Эти значения по запросу владельца заменяют рекомендации раздела 8 для данного портфолио.
- Обводки рисуются внутри карточек и не участвуют в расчёте ширины. Полосы прокрутки скрыты; длинные описания доступны колесом, касанием и клавиатурой.
- Логотипы не перекрашиваются общим фильтром. Next.js использует локальный SVG с тёмным кругом и белым знаком, одинаковый в обеих темах.
